A layer-based layout that keeps both hands on the home row: a numpad on the left ⌘, symbols and arrows on Caps Lock, mouse keys on ⌥, and a Dvorak layer toggled with ⌥+Esc. Source: cafe6a6e/karabiner

Key Behavior
Left ⌘ + right-hand keys Numpad: m,. → 1 2 3, jkl → 4 5 6, uio → 7 8 9, Space → 0. Use right ⌘ for shortcuts.
Right ⌘ ⌘ when held; tap alone for ⌃+Space (input source switch)
[ / ' Delete / Return
Caps Lock Tap for Esc. Hold for arrows on hjkl, [ ] on ui, ' on m, - on ;, \ on /. Mouse motion scrolls while held.
Tab (hold) Shifted numbers (! @ # …) on the numpad positions
⌥ + keys Mouse keys: move on hjkl, click on uio / fds; left ⌥ + nm,. scrolls ← ↓ ↑ →
⌥ + Esc Toggle the Dvorak layer (physical Esc only). / is on the q key; ' and [ ] stay on the Caps Lock layer.
Rule order

Karabiner-Elements uses the first matching rule, so keep the rules in the order they are listed here. In particular, the Dvorak rule must stay below the [/' and left ⌘ numpad rules, and the mouse-motion scroll rule needs the Caps Lock rule enabled.
